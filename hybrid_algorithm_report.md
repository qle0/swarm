Разработан и протестирован инновационный гибридный алгоритм планирования пути, который динамически комбинирует различные стратегии планирования для достижения оптимальной производительности в зависимости от условий задачи.

## 🧬 Архитектура гибридного алгоритма

### Основные компоненты:

1. **Анализатор сложности** - оценивает сложность задачи планирования
2. **Селектор стратегии** - выбирает оптимальную стратегию планирования
3. **Менеджер времени** - управляет бюджетом времени на планирование
4. **Координатор планировщиков** - управляет выполнением базовых алгоритмов

### Доступные стратегии:

#### 🎯 **Adaptive** (Адаптивная)
- **Принцип:** Автоматический выбор планировщика на основе сложности задачи
- **Логика выбора:**
  - Простые задачи (сложность < 0.3) → A*
  - Средние задачи (0.3-0.6) → Adaptive RRT
  - Сложные задачи (0.6-0.8) → Dijkstra
  - Очень сложные (> 0.8) → RRT*
- **Результат:** Score 0.924, Success Rate 93.3%

#### ⚡ **Fast First** (Быстрый старт)
- **Принцип:** Сначала быстрое планирование, затем улучшение качества
- **Этапы:**
  1. RRT Optimized для быстрого результата
  2. A* для улучшения качества (если есть время)
- **Результат:** Score 0.967, Success Rate 100%

#### 🏆 **Quality First** (Качество прежде всего)
- **Принцип:** Приоритет качественному планированию
- **Этапы:**
  1. Dijkstra для максимального качества
  2. RRT Optimized как fallback при нехватке времени
- **Результат:** Score 0.989, Success Rate 100%

#### 🔄 **Parallel** (Параллельная)
- **Принцип:** Имитация параллельного выполнения нескольких алгоритмов
- **Алгоритмы:** RRT Optimized, A*, Adaptive RRT
- **Выбор:** Лучший результат из всех выполненных
- **Результат:** Score 0.995, Success Rate 100% ⭐

#### 🏗️ **Hierarchical** (Иерархическая)
- **Принцип:** Двухуровневое планирование
- **Уровни:**
  1. Грубое планирование (RRT Optimized)
  2. Детальное планирование (A*)
- **Результат:** Score 0.973, Success Rate 100%

#### 🎭 **Multi-Stage** (Многоэтапная)
- **Принцип:** Последовательное применение алгоритмов с распределением времени
- **Этапы:**
  1. RRT Optimized (30% времени)
  2. Adaptive RRT (40% времени)
  3. A* (30% времени)
- **Результат:** Score 0.974, Success Rate 100%
