# Результаты обучения модели дрона

## Обучение модели

Было проведено обучение модели с использованием алгоритма PPO (Proximal Policy Optimization) из библиотеки Stable Baselines 3. Обучение проводилось в два этапа:

1. Первое обучение: 10,000 шагов
2. Второе обучение: 50,000 шагов

## Результаты тестирования

### После первого обучения (10,000 шагов)
```
Success: False
Time    : 30.02 s
Energy  : 9.9 J
Score   : 0.000
```

### После второго обучения (50,000 шагов)
```
Success: False
Time    : 30.02 s
Energy  : 66.1 J
Score   : 0.000
```

## Выводы

Хотя модель не достигла успеха в выполнении задачи (достижение цели), наблюдается прогресс в обучении:

1. Увеличение потребления энергии с 9.9 J до 66.1 J указывает на то, что дрон начал активно двигаться, а не просто оставаться на месте.
2. Для достижения успеха, вероятно, требуется значительно больше шагов обучения (возможно, несколько миллионов).
3. Также может потребоваться настройка гиперпараметров алгоритма PPO для улучшения результатов.

## Реализованные улучшения

### Добавлены новые алгоритмы обучения с подкреплением:
1. **PPO (Proximal Policy Optimization)** - исходный алгоритм
2. **A2C (Advantage Actor-Critic)** - более простой и часто более стабильный алгоритм
3. **SAC (Soft Actor-Critic)** - алгоритм, оптимизированный для непрерывных пространств действий

### Добавлены алгоритмы планирования пути:
1. **RRT (Rapidly-exploring Random Tree)** - алгоритм для быстрого исследования пространства и нахождения пути
2. **Алгоритм Дейкстры** - классический алгоритм поиска кратчайшего пути на графе

## Использование новых алгоритмов

### Обучение с использованием различных алгоритмов RL:
```bash
# Обучение с использованием PPO (по умолчанию)
python RL/train_RL.py --algorithm ppo --timesteps 50000

# Обучение с использованием A2C
python RL/train_RL.py --algorithm a2c --timesteps 50000

# Обучение с использованием SAC
python RL/train_RL.py --algorithm sac --timesteps 50000
```

### Использование алгоритмов планирования пути:
```bash
# Использование RRT
python RL/train_RL.py --planner rrt

# Использование алгоритма Дейкстры
python RL/train_RL.py --planner dijkstra
```

### Тестирование:
```bash
# Тестирование обученной модели
python RL/test_RL.py --model model/ppo_policy.zip

# Тестирование с использованием RRT
python RL/test_RL.py --planner rrt

# Тестирование с использованием алгоритма Дейкстры
python RL/test_RL.py --planner dijkstra
```
