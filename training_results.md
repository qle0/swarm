# Результаты обучения модели дрона

## Обучение модели

Было проведено обучение модели с использованием алгоритма PPO (Proximal Policy Optimization) из библиотеки Stable Baselines 3. Обучение проводилось в два этапа:

1. Первое обучение: 10,000 шагов
2. Второе обучение: 50,000 шагов

## Результаты тестирования

### После первого обучения (10,000 шагов)
```
Success: False
Time    : 30.02 s
Energy  : 9.9 J
Score   : 0.000
```

### После второго обучения (50,000 шагов)
```
Success: False
Time    : 30.02 s
Energy  : 66.1 J
Score   : 0.000
```

## Выводы

Хотя модель не достигла успеха в выполнении задачи (достижение цели), наблюдается прогресс в обучении:

1. Увеличение потребления энергии с 9.9 J до 66.1 J указывает на то, что дрон начал активно двигаться, а не просто оставаться на месте.
2. Для достижения успеха, вероятно, требуется значительно больше шагов обучения (возможно, несколько миллионов).
3. Также может потребоваться настройка гиперпараметров алгоритма PPO для улучшения результатов.

## Следующие шаги

1. Увеличить количество шагов обучения до 1-5 миллионов
2. Настроить гиперпараметры алгоритма PPO
3. Рассмотреть возможность использования других алгоритмов обучения с подкреплением
