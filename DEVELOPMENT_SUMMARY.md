## 📊 Примеры использования

### Быстрый старт
```bash
# Настройка среды
./examples/scripts/setup_dev_environment.sh

# Быстрое обучение
python examples/training/train_advanced.py --quick --experiment-name test_model

# Тестирование
python examples/testing/comprehensive_test.py --model models/test_model_final.zip
```

### Продакшен пайплайн
```bash
# Полный автоматизированный пайплайн
python examples/automation/full_pipeline.py \
    --experiment-name production_v1 \
    --config examples/configs/training_config.yaml:production
```

### Curriculum Learning
```bash
# Обучение с постепенным усложнением
python examples/training/train_advanced.py \
    --config examples/configs/training_config.yaml:curriculum \
    --experiment-name curriculum_model
```

## 🎯 Результаты и метрики

### Структура результатов
```
pipeline_results/
└── experiment_name/
    ├── models/              # Сохраненные модели
    ├── logs/               # TensorBoard логи
    ├── results/            # Результаты тестирования
    ├── pipeline_report.json # Полный отчет
    └── summary.txt         # Краткое резюме
```

### Ключевые метрики
- **Success Rate**: Процент успешных миссий
- **Average Reward**: Средняя награда за эпизод
- **Flight Time**: Время выполнения миссии
- **Energy Consumption**: Потребление энергии
- **Robustness Score**: Устойчивость к сложным сценариям

## 🔧 Технические особенности

### Архитектура обучения
- **Алгоритм**: PPO (Proximal Policy Optimization)
- **Сеть**: MLP с настраиваемой архитектурой
- **Пространство наблюдений**: 20D кинематическое состояние
- **Пространство действий**: 4D RPM управление моторами

### Среда симуляции
- **Физический движок**: PyBullet
- **Модель дрона**: Crazyflie 2.0
- **Частота симуляции**: 50 Hz (dt=0.02s)
- **Горизонт**: 30 секунд
- **Пространство задач**: 3D навигация с препятствиями

### Функция награды
- **Успех миссии**: 70% веса
- **Временная эффективность**: 15% веса  
- **Энергетическая эффективность**: 15% веса
