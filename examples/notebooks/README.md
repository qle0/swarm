# 📓 Jupyter Notebooks для анализа Swarm

Этот каталог содержит интерактивные Jupyter notebooks для анализа данных, визуализации результатов и экспериментов с моделями Swarm.

## 📋 Планируемые notebooks:

### 1. `data_analysis.ipynb`
- Анализ результатов обучения
- Визуализация метрик производительности
- Сравнение различных моделей

### 2. `model_comparison.ipynb`
- Сравнение архитектур моделей
- A/B тестирование различных подходов
- Анализ гиперпараметров

### 3. `environment_exploration.ipynb`
- Исследование пространства задач
- Анализ сложности различных сценариев
- Визуализация траекторий полета

## 🚀 Запуск notebooks

```bash
# Активация окружения
source miner_env/bin/activate

# Установка Jupyter
pip install jupyter notebook ipywidgets matplotlib seaborn

# Запуск Jupyter
jupyter notebook examples/notebooks/
```

Notebooks будут добавлены в следующих обновлениях.
