# Анализ ключевых компонентов подсети Swarm

## Обзор архитектуры

Подсеть Swarm представляет собой децентрализованную систему для автономного полета дронов, построенную на платформе Bittensor. Система использует обучение с подкреплением (RL) для обучения политик управления дронами и оценивает их в симулированной среде PyBullet.

## Ключевые компоненты и их взаимосвязи

### 1. Базовая архитектура

**BaseNeuron** - корневой класс для всех участников сети:
- Управляет подключением к Bittensor
- Обеспечивает синхронизацию с блокчейном
- Реализует базовую логику нейронов

**BaseValidatorNeuron** и **BaseMinerNeuron** наследуют от BaseNeuron и добавляют специфичную функциональность.

### 2. Протокол коммуникации

Система использует специализированный протокол для обмена данными:

- **PolicySynapse** - основной канал связи между валидаторами и майнерами
- **PolicyRef** - метаданные модели (SHA256, framework, размер)
- **PolicyChunk** - фрагменты данных модели для передачи
- **MapTask** - задание для дрона (стартовая точка, цель, параметры)
- **ValidationResult** - результат оценки модели

### 3. Валидатор (Validator)

Центральный компонент системы, выполняющий следующие функции:

#### Генерация задач:
- Создает случайные MapTask с радиальными целями (10-30м от старта)
- Использует детерминированную генерацию с seed'ами
- Обеспечивает воспроизводимость результатов

#### Оценка моделей:
- Запрашивает PolicyRef у майнеров
- Загружает модели при несовпадении SHA256
- Выполняет оценку в изолированных подпроцессах
- Использует PyBullet для физической симуляции

#### Система наград:
```
Score = 0.70 × Success + 0.15 × (1 - t/horizon) + 0.15 × (1 - e/budget)
```
- 70% - успешное выполнение миссии
- 15% - эффективность по времени
- 15% - энергоэффективность

#### Управление весами:
- Экспоненциальное усиление лучших результатов
- EMA (Exponential Moving Average) для сглаживания
- Burn механизм - 90% эмиссий сжигается

### 4. Майнер (Miner)

Предоставляет предобученные RL политики:

#### Модель:
- Поддерживает Stable Baselines 3 (PPO)
- Модели упакованы в ZIP архивы
- Размер ограничен 10MB

#### Безопасность:
- Whitelist валидаторов
- SHA256 проверка целостности
- Аутентификация через hotkey

### 5. Система безопасности

#### Безопасность моделей:
- Ограничение размера (<10MB)
- SHA256 проверка целостности
- Валидация ZIP архивов
- Защита от path traversal

#### Безопасность выполнения:
- Изолированные подпроцессы
- Ограничение памяти (8GB RSS)
- Таймауты выполнения (120 сек)
- Автоочистка ресурсов

#### Сетевая безопасность:
- Bittensor криптография
- Hotkey аутентификация
- Таймауты запросов (30 сек)
- Rate limiting

### 6. Ядро системы

#### Симуляция дрона:
- PyBullet физический движок
- Реалистичная модель квадрокоптера
- Энергетическая модель
- Визуализация (опционально)

#### Оценщик (Evaluator):
- Изолированное выполнение в подпроцессах
- Загрузка и тестирование моделей
- Сбор метрик производительности
- Обработка ошибок

## Поток взаимодействия

1. **Инициация**: Валидатор генерирует случайную MapTask
2. **Запрос**: Отправляет PolicySynapse.request_ref() майнерам
3. **Ответ**: Майнеры возвращают PolicyRef с метаданными
4. **Проверка**: Валидатор сравнивает SHA256 с кешем
5. **Загрузка**: При необходимости запрашивает модель через PolicyChunk
6. **Оценка**: Запускает изолированный подпроцесс с evaluator.py
7. **Симуляция**: Тестирует модель в PyBullet среде
8. **Награда**: Вычисляет score по формуле
9. **Веса**: Обновляет веса с EMA и boost
10. **Блокчейн**: Записывает веса в Bittensor

## Ключевые особенности

### Децентрализация:
- Майнеры независимо разрабатывают политики
- Валидаторы независимо оценивают
- Консенсус через Bittensor механизм

### Безопасность:
- Многоуровневая защита
- Изоляция выполнения
- Криптографическая аутентификация

### Масштабируемость:
- До 256 майнеров за цикл
- Параллельная оценка
- Эффективное кеширование

### Справедливость:
- Детерминированная оценка
- Случайная выборка майнеров
- EMA сглаживание результатов

## Технические характеристики

- **Частота циклов**: 300 секунд
- **Размер выборки**: до 256 майнеров
- **Таймаут оценки**: 120 секунд
- **Таймаут сети**: 30 секунд
- **Лимит модели**: 10 MB
- **Лимит памяти**: 8 GB RSS
- **Burn rate**: 90% эмиссий

## Заключение

Подсеть Swarm представляет собой сложную, но хорошо структурированную систему для децентрализованного обучения автономных дронов. Архитектура обеспечивает баланс между производительностью, безопасностью и справедливостью, создавая стимулы для разработки эффективных алгоритмов управления дронами.

Ключевые преимущества:
- Открытость и прозрачность алгоритмов
- Децентрализованная разработка
- Строгая система безопасности
- Справедливая система оценки
- Масштабируемость решения

Система может служить основой для развития более сложных задач автономной навигации и найти применение в исследованиях и промышленности.
