# Анализ процесса майнинга в подсети Swarm

## Обзор

Майнинг в подсети Swarm представляет собой процесс разработки, обучения и предоставления политик управления дронами с использованием обучения с подкреплением (Reinforcement Learning). Майнеры соревнуются в создании наиболее эффективных алгоритмов автономного полета, которые оцениваются валидаторами в симулированной среде.

## Архитектура майнера

### Базовые компоненты

**BaseMinerNeuron** - основной класс майнера:
- Наследует функциональность от BaseNeuron
- Управляет жизненным циклом майнера
- Обеспечивает синхронизацию с сетью Bittensor
- Реализует базовую логику обработки запросов

**Конфигурация и инициализация**:
- Загрузка параметров из командной строки
- Инициализация wallet и подключения к subtensor
- Настройка Axon сервера для приема запросов
- Проверка наличия и валидности модели

### Сетевые компоненты

**Axon сервер**:
- Принимает входящие запросы от валидаторов
- Обрабатывает PolicySynapse сообщения
- Реализует функции forward, blacklist, priority
- Поддерживает асинхронную обработку

**Bittensor интеграция**:
- Подключение к блокчейну через subtensor
- Синхронизация с metagraph
- Управление wallet и криптографическими ключами
- Регистрация в сети и поддержание статуса

### Система безопасности

**Whitelist механизм**:
```python

**Аутентификация и авторизация**:
- Проверка hotkey валидатора
- Верификация подписи запроса
- Контроль доступа по whitelist
- Приоритизация по стейку

**Защитные механизмы**:
- Blacklist для блокировки вредоносных запросов
- Rate limiting для предотвращения DDoS
- Таймауты для защиты от зависших соединений
- Валидация входящих данных

```

### 2. Обучение RL модели

**Среда обучения**:
- PyBullet физический движок
- Симуляция квадрокоптера с реалистичной физикой
- Случайно генерируемые задачи (MapTask)
- Наблюдения: позиция, скорость, ориентация
- Действия: RPM четырех моторов

**Алгоритм PPO (Proximal Policy Optimization)**:
```python
from stable_baselines3 import PPO
from swarm.utils.env_factory import make_env

# Создание среды
task = random_task(sim_dt=SIM_DT, horizon=HORIZON_SEC, seed=1)
env = make_env(task, gui=False)

# Инициализация агента
model = PPO("MlpPolicy", env, verbose=1)

# Обучение
model.learn(total_timesteps=1000000)

# Сохранение модели
model.save("model/ppo_policy")
```

**Параметры обучения**:
- Политика: MlpPolicy (Multi-Layer Perceptron)
- Пространство действий: Continuous (4D RPM)
- Функция награды: 0.7×успех + 0.15×время + 0.15×энергия
- Горизонт эпизода: 30 секунд
- Частота симуляции: 50 Hz
- Learning rate: 3e-4
- Discount factor: 0.99

## Протокол взаимодействия с валидаторами

### Двухэтапный handshake

**Этап 1: Запрос метаданных**
```python
# Валидатор → Майнер
synapse = PolicySynapse.request_ref()

# Майнер → Валидатор  
ref = PolicyRef(
    sha256=self._sha256,
    entrypoint=self.ENTRYPOINT,
    framework=self.FRAMEWORK,
    size_bytes=self._size
)
return PolicySynapse.from_ref(ref)
```

**Этап 2: Передача модели (при необходимости)**
```python
# Валидатор → Майнер
synapse = PolicySynapse.request_blob()

# Майнер → Валидатор
raw_bytes = self.POLICY_PATH.read_bytes()
b64_str = base64.b64encode(raw_bytes).decode("ascii")
chunk = PolicyChunk(sha256=self._sha256, data=b64_str)
return PolicySynapse.from_chunk(chunk)
```

### Поток обработки запросов

1. **Прием запроса** - Axon получает PolicySynapse
2. **Аутентификация** - Проверка hotkey валидатора
3. **Авторизация** - Проверка whitelist
4. **Определение типа** - PolicyRef или PolicyChunk
5. **Генерация ответа** - Подготовка данных
6. **Отправка** - Возврат результата валидатору
7. **Логирование** - Запись события

## Жизненный цикл майнера

### Инициализация
```python
def __init__(self, config=None):
    super().__init__(config=config)
    self.load_state()
    
    # Проверка модели
    if not self.POLICY_PATH.exists():
        raise FileNotFoundError(f"Model not found: {self.POLICY_PATH}")
    
    # Вычисление хеша
    self._sha256 = sha256sum(self.POLICY_PATH)
    self._size = self.POLICY_PATH.stat().st_size
```

### Основной цикл
```python
def run(self):
    # Синхронизация с сетью
    self.sync()
    
    # Запуск Axon сервера
    self.axon.serve(netuid=self.config.netuid, subtensor=self.subtensor)
    self.axon.start()
    
    # Основной цикл
    while not self.should_exit:
        # Ожидание обновления metagraph
        while (self.block - self.metagraph.last_update[self.uid] 
               < self.config.neuron.epoch_length):
            time.sleep(1)
            if self.should_exit:
                break
        
        # Синхронизация
        self.sync()
        self.step += 1
```

## Экономическая модель

### Система стимулов

**Награды майнеров**:
- Пропорциональны качеству модели
- Учитывают успешность, скорость, эффективность
- Обновляются каждые 300 секунд

**Формула награды**:
```
Score = 0.70 × Success + 0.15 × (1 - t/horizon) + 0.15 × (1 - e/budget)
```

**Burn механизм**:
- 90% эмиссий сжигается
- 10% распределяется между майнерами
- Стимулирует качество над количеством

### ROI анализ

**Затраты**:
- Вычислительные ресурсы для обучения
- Электроэнергия для майнинга
- Время разработки алгоритмов

**Доходы**:
- TAO токены за качественные модели
- Долгосрочная стоимость интеллектуальной собственности
- Репутация в экосистеме

**Операционная безопасность**:

## Заключение

Процесс майнинга в подсети Swarm представляет собой сложную систему, объединяющую передовые технологии машинного обучения, блокчейн инфраструктуру и экономические стимулы. Успешный майнер должен:

1. **Разработать эффективные RL алгоритмы** для управления дронами
2. **Обеспечить надежную инфраструктуру** для непрерывной работы
3. **Поддерживать высокий уровень безопасности** системы
4. **Постоянно оптимизировать** производительность моделей
5. **Адаптироваться к изменениям** в протоколе и требованиях

Подсеть Swarm создает уникальную экосистему, где экономические стимулы направлены на развитие открытых технологий автономного полета, что может привести к значительным прорывам в области робототехники и искусственного интеллекта.
