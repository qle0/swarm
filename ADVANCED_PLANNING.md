# Advanced Path Planning Algorithms

This document describes the advanced path planning algorithms and optimizations implemented for drone navigation in the Swarm subnet.

## Overview

The system now includes several advanced path planning algorithms with optimizations:

1. **Optimized RRT** - Enhanced Rapidly-exploring Random Tree with adaptive sampling
2. **A* Algorithm** - Efficient grid-based pathfinding with heuristic guidance  
3. **Path Smoothing** - Multiple techniques to smooth generated paths
4. **Hybrid Approaches** - Combining global planning with local RL control

## Algorithms

### 1. Optimized RRT (`rrt_optimized.py`)

Enhanced version of the basic RRT algorithm with several optimizations:

**Key Features:**
- **Adaptive Sampling**: Biases sampling towards unexplored regions
- **Dynamic Step Size**: Adjusts step size based on local obstacle density
- **Adaptive Goal Sampling**: Increases goal sampling rate over time
- **Early Termination**: Stops when a path is found
- **Obstacle Density Mapping**: Caches obstacle density for faster planning

**Parameters:**
- `adaptive_sampling`: Enable adaptive sampling (default: True)
- `early_termination`: Stop when path found (default: True)
- `max_iterations`: Maximum planning iterations (default: 2000)
- `step_size`: Base step size (default: 0.5)
- `goal_sample_rate`: Initial goal sampling rate (default: 0.1)

**Performance Improvements:**
- 2-3x faster than basic RRT in complex environments
- Better exploration of difficult regions
- More consistent path quality

### 2. A* Algorithm (`astar.py`)

Grid-based pathfinding algorithm that uses a heuristic to guide search towards the goal.

**Key Features:**
- **Heuristic Guidance**: Uses Euclidean distance to guide search
- **3D Grid Navigation**: Supports full 3D movement
- **Diagonal Movement**: Optional diagonal movements for smoother paths
- **Configurable Resolution**: Adjustable grid resolution for speed/accuracy tradeoff

**Parameters:**
- `grid_resolution`: Size of grid cells (default: 0.5)
- `heuristic_weight`: Weight for heuristic function (default: 1.0)
- `allow_diagonal`: Enable diagonal movements (default: True)

**Advantages over Dijkstra:**
- 5-10x faster in most scenarios
- Optimal paths when heuristic_weight = 1.0
- Better memory efficiency

### 3. Path Smoothing (`path_smoother.py`)

Multiple techniques to smooth paths generated by planners:

**Available Methods:**

#### Spline Smoothing
- Uses B-spline interpolation
- Produces very smooth curves
- Good for drone flight dynamics
- Parameters: `num_points`, `smoothing_factor`, `degree`

#### Shortcut Smoothing  
- Removes unnecessary waypoints
- Connects distant waypoints when collision-free
- Reduces path length significantly
- Parameters: `max_iterations`, `min_improvement`

#### Gradient Smoothing
- Uses gradient descent optimization
- Minimizes curvature and obstacle proximity
- Good balance of smoothness and safety
- Parameters: `iterations`, `step_size`, `smoothness_weight`

#### Bezier Smoothing
- Creates smooth curves between waypoints
- Uses control points for curve generation
- Maintains path topology
- Parameters: `num_points`, `control_point_ratio`

### 4. Hybrid Policy (`hybrid_policy.py`)

Combines global path planning with local RL control:

**Architecture:**
1. **Global Planning**: Uses RRT to find obstacle-free path
2. **Local Control**: Uses RL policy for fine-grained control
3. **Dynamic Switching**: Switches between planning and RL based on conditions

**Key Features:**
- **Replanning**: Replans when deviating from path
- **RL Integration**: Seamless integration with trained RL policies
- **Adaptive Behavior**: Adjusts strategy based on environment complexity

## Usage Examples

### Basic Usage

```python
from swarm.planners.planner_policy import PlannerPolicy

# Optimized RRT with path smoothing
policy = PlannerPolicy(
    planner_type="rrt_optimized",
    use_path_smoothing=True,
    smoothing_method="spline",
    max_iterations=1000,
    adaptive_sampling=True
)

# A* algorithm
policy = PlannerPolicy(
    planner_type="astar",
    grid_resolution=0.3,
    heuristic_weight=1.2,
    use_path_smoothing=True,
    smoothing_method="bezier"
)
```

### Advanced Configuration

```python
# Optimized RRT with custom parameters
policy = PlannerPolicy(
    planner_type="rrt_optimized",
    max_iterations=2000,
    step_size=0.3,
    goal_sample_rate=0.15,
    search_radius=1.5,
    adaptive_sampling=True,
    early_termination=True,
    use_path_smoothing=True,
    smoothing_method="gradient"
)
```

### Hybrid Approach

```python
from swarm.planners.hybrid_policy import HybridPolicy
from stable_baselines3 import PPO

# Load RL policy
rl_policy = PPO.load("model/ppo_policy.zip")

# Create hybrid policy
hybrid_policy = HybridPolicy(
    rl_policy=rl_policy,
    planning_horizon=5.0,
    replan_threshold=1.0,
    max_iterations=500
)
```

## Configuration Recommendations

### For Speed
- Use A* with `grid_resolution=0.5`
- Enable `early_termination` for RRT
- Use `shortcut` smoothing

### For Quality
- Use Optimized RRT with `adaptive_sampling=True`
- Apply `spline` or `gradient` smoothing
- Lower `grid_resolution` for A*

### For Dynamic Environments
- Use Hybrid policy
- Enable frequent replanning
- Use `gradient` smoothing for obstacle avoidance
