# 🧪 Система тестирования Success Score алгоритмов

Этот набор инструментов предназначен для комплексного тестирования и анализа производительности алгоритмов планирования пути в проекте Swarm.

## 📁 Структура файлов

### Основные тестовые файлы:

1. **`test_success_score.py`** - Базовый тест с имитацией алгоритмов
   - Простое тестирование с моделированием поведения алгоритмов
   - Быстрый запуск для первичной оценки
   - Подходит для демонстрации концепции

2. **`test_algorithms_simple.py`** - Упрощенное тестирование реальных алгоритмов
   - Реализация упрощенных версий планировщиков
   - Тестирование на различных сценариях
   - Детальная оценка success score

3. **`test_real_algorithms.py`** - Попытка интеграции с реальными планировщиками
   - Использование реальных классов из проекта swarm
   - Требует полной установки зависимостей
   - Наиболее точные результаты

4. **`detailed_performance_test.py`** - Детальный анализ производительности
   - Тестирование на сценариях различной сложности
   - Анализ масштабирования и деградации
   - Рекомендации по выбору алгоритмов

5. **`final_report.py`** - Генератор финального отчета
   - Создание детального Markdown отчета
   - Сводная статистика и рекомендации
   - Профессиональное оформление результатов

### Вспомогательные файлы:

- **`algorithm_performance_report.md`** - Детальный отчет в формате Markdown
- **`README_TESTING.md`** - Данная документация

## 🔧 Технические детали

### Метрики оценки:

1. **Success Score** (0.0 - 1.0):
   - Базовый score за достижение цели: 0.7
   - Бонус за эффективность пути: до 0.3
   - Учитывает отношение прямого расстояния к длине пути

2. **Success Rate** (%):
   - Процент успешных планирований
   - Путь считается успешным, если достигает цели с точностью 1м

3. **Planning Time** (секунды):
   - Время выполнения алгоритма планирования
   - Включает все вычисления до получения результата

4. **Stability**:
   - Обратная величина стандартного отклонения scores
   - Показывает консистентность результатов

### Сценарии тестирования:

- **Очень легкий** (0.1): Короткий прямой путь 5м
- **Легкий** (0.3): Средний путь с отклонением ~11м  
- **Средний** (0.5): Длинный путь с изменением высоты ~18м
- **Сложный** (0.7): Очень длинный путь ~30м
- **Очень сложный** (0.9): Экстремально длинный путь ~35м
